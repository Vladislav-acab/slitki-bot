Инструкция по запуску Telegram-бота "Slitki Bot" на Railway:

1. Подготовка:
   - Зарегистрируйтесь на https://railway.app
   - Создайте новый проект (Blank Project)
   - Загрузите файлы из этого архива: slitki_bot.py и requirements.txt

2. Настройка:
   - Перейдите во вкладку Settings
   - В поле Start Command укажите: python slitki_bot.py

3. Готово:
   - Railway автоматически установит зависимости и запустит бота
   - Бот будет принимать заказы и пересылать их в Telegram-группу
